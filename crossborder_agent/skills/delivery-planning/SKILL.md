# Delivery Planning

Plan for the required contract: three localized descriptions, one hero image, five detail images, one video, and one strategy document within 30 minutes.

Use the supplied fact ledger and taxonomy as immutable evidence. Prioritize A1 compliance, A2 parseability/specifications, A3 taxonomy, and A5 factual consistency before creative polish. Allocate remaining effort to localization, image-set usefulness, and video stability.

Give every visual slot a distinct commercial job. Prefer a coherent sequence over six independent attractive images. Reserve repair budget for observed defects; do not schedule speculative retries.

When all source images need cleanup but still show the product clearly, schedule image editing from the best identity references instead of declaring the image model unavailable. Keep `no eligible reference`, `model/API unavailable`, `candidate rejected`, and `download failure` as separate observable outcomes. Direct source fallback is an emergency completeness path and must be labeled as degraded when it does not pass listing readiness.

Repairs must be bounded, target one existing artifact, preserve the last usable version until a better revision is accepted, and stop when the evaluator accepts the delivery or the repair/time budget is exhausted.

Treat free-form planning text as internal, untrusted guidance. Do not copy localization suggestions, inferred measurements, brand interpretations, or other model-authored claims into the customer-facing strategy document. Expose only allowlisted execution controls and facts that can be recomputed from the fact ledger and run state.

Do not request external systems, built-in model tools, local-file uploads, memory, retrieval, or MCP. Only the declared local tool catalog is available.

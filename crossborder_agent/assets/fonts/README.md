# Bundled table font

`NotoSansCJK-Regular.ttc` is Noto Sans CJK Regular from the official
[`notofonts/noto-cjk`](https://github.com/notofonts/noto-cjk) repository.

- Upstream path: `Sans/OTC/NotoSansCJK-Regular.ttc`
- SHA-256: `b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`
- License: SIL Open Font License 1.1; see `OFL-1.1.txt` in this directory.

The font is included so source-grounded table cells and model-authored labels
remain readable in Simplified Chinese, Traditional Chinese, Japanese, Korean,
Portuguese, and English on the minimal Debian evaluation image.

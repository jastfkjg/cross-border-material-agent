 Background
This event requires users to create an Agent which focuses on generating localized assets for cross-border e-commerce products. For cross-border e-commerce sellers, listing the same product in a new market requires an entirely new set of localized assets: product copy that reads naturally in the local language, a main image and product detail images that meet the platform's requirements, and a product video. Markets vary in language, sizing systems, spelling conventions, and cultural sensitivities, so the traditional approach requires operations, design, and translation teams to work together. Based on a real-world e-commerce scenario, this task challenges participants to build an Agent that can generate a complete set of localized product assets end to end in a single run.

AI builders, e-commerce professionals, teams, and individual developers are welcome to enter.
